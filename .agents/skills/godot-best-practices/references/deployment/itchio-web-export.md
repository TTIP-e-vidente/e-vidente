# itch.io Web Export Guide (Godot 4.x)

Deployment-focused checklist for stable and efficient browser builds.

## Why Web Requires Extra Rules

Web exports run inside browser constraints:

- CPU/GPU budgets vary heavily by device.
- Download size directly affects retention.
- Some engine features depend on browser headers you do not control on itch.io.

## 1) Export Preset Baseline

Create a dedicated Web preset in `export_presets.cfg`:

- Renderer: `Compatibility` for maximum browser coverage.
- Threads: Disabled unless your host supports required cross-origin isolation headers.
- Compression and quality tuned for fast first load.
- Extension support: keep optional features minimal.

Important for itch.io:

- itch.io usually does not provide the headers needed for SharedArrayBuffer-based threading.
- Prefer single-thread-safe gameplay paths for reliability.

## 2) Build Size Budgeting

Define budgets early and enforce them:

- Initial downloadable payload target (example): less than 30 MB.
- Texture budget per chapter/scene.
- Audio compression policy (music vs short SFX).

Practical actions:

- Merge repeated UI icons into atlases.
- Remove hidden/unused textures from exports.
- Keep only required locales/fonts in web package.

## 3) Asset Strategy For Browser

- Prefer compressed textures that keep visual readability.
- Avoid loading huge full-screen textures for small UI regions.
- Preload only critical first-screen resources.
- Stream or deferred-load optional content after menu entry.

## 4) Input and UX For itch.io

- Ensure keyboard-only path works from first interaction.
- Validate pointer interactions for both mouse and touch.
- Keep UI elements readable in embedded iframe sizes.
- Test pause/resume behavior when browser tab visibility changes.

## 5) Runtime Stability Checks

Before publishing, validate at least:

- Fresh browser cache first run.
- Re-entry run (cached assets path).
- Low-end laptop or throttled profile.
- Mobile browser sanity pass (if mobile is in scope).

## 6) Upload Package Structure

Typical package for itch.io HTML game:

- HTML shell generated by Godot.
- `.wasm` and `.pck` files.
- Any required side files generated by export.

Keep paths flat and deterministic to avoid iframe loading surprises.

## 7) CI and Automation Recommendations

- Keep headless import + smoke tests for regressions.
- Add a size check step that fails if package grows beyond budget.
- Store a per-build manifest (asset counts and top heavy files).

## 8) Pre-Publish Checklist

- Export preset uses web-safe options for itch.io.
- No thread-dependent code path is required to play.
- Initial scene loads under target time on average hardware.
- Core loop is playable with keyboard and mouse.
- Build size is within agreed budget.
- At least one full run from menu to completion passes in browser.
